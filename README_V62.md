# CiviCoach v62 — commandes audio dessinées

Les commandes Lire, Pause / reprendre et Arrêter sont des boutons au clavier et à la souris, illustrés par des dessins SVG originaux. Les libellés accessibles, les commandes audio et les licences sont conservés.

Les crédits sont rangés dans « Source audio ». Les fiches de La Marseillaise ont deux repères courts, une image moins large et davantage de place pour le texte. Les questions sur les paroles conservent la phrase à mémoriser.

Dans un PDF, le bouton dessiné de lecture est un lien vers le lecteur du site, qui propose les trois commandes. Un PDF n’exécute pas lui-même la lecture, la pause ou l’arrêt audio.

Source vérifiée le 13 octobre 2026 : https://www.elysee.fr/la-presidence/la-marseillaise-de-rouget-de-lisle

Après remplacement des fichiers et publication sur GitHub, recharger avec Ctrl+F5. Les médias sont inclus ; aucune nouvelle dépendance externe n’est nécessaire.
