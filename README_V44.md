# CiviCoach — version 44

- Reprise du dernier score du même examen lors du bilan de progression : historique enregistré, ancien résultat sauvegardé dans les variables et écran de chat restauré. Le score précédent peut toujours être choisi ou modifié dans la liste. Sans résultat correspondant, aucun score n’est inventé.
- Les liens « Relire le chapitre » des feedbacks sont remplacés par un conseil en texte indiquant la notion et le chapitre, sans navigation supplémentaire.
- Les autres fonctionnalités de la version 43 sont conservées.

Installation : remplacer les fichiers du projet GitHub et actualiser le code Moodle avec moodle/INTEGRATION_BODY_MULTI_COURS.html. Fermer les anciennes fenêtres avant de rouvrir CiviCoach.

Vérifications : parcours depuis un résultat réel vers le bilan de progression, ancienne sauvegarde, restauration du chat, sélection du même examen, modification manuelle, conseils sans lien, feedbacks, questions et reprise d’activité. Validation de tous les écrans et liens réussie. Le score reste dépendant des résultats disponibles dans le navigateur utilisé.
