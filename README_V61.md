# CiviCoach v61
Remplacer les fichiers du site par le contenu de cette archive, puis pousser sur GitHub. Conserver les dossiers et les nouveaux fichiers fiches-contenus.js, fiches-audio.js et audio-fiches.html. Recharger avec Ctrl+F5 après publication.

Les fiches des bilans initiaux/de progression, examens, entraînements et résultats sauvegardés utilisent le même moteur. Les réglages de daltonisme et de texte agrandi s’appliquent lors de l’export PDF. Aucun document n’est proposé sans erreur détaillée.

Deux notes par notion, sans flèche décorative ; portraits et objets séparés. Les sources et licences sont dans SOURCES_FICHES_V61.md. Les trois extraits audio sont inclus dans chatbot/assets/audio.

Le workflow de compilation des bases Excel reste opérationnel. Les contenus pédagogiques personnalisés se trouvent dans chatbot/fiches-contenus.js ; les autres notions sont reconstruites à partir des réponses et explications des bases.

Les PDF du dossier exemples permettent de vérifier le rendu avant déploiement.
