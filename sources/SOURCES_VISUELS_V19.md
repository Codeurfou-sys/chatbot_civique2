## Couvertures de livres

Reproductions de couvertures réelles utilisées pour identifier les œuvres dans l’exercice. Elles ne sont pas présentées comme des images libres de droits ; les droits des illustrations et éditions restent ceux de leurs titulaires. Le nom de l’auteur est masqué uniquement dans l’interface, les images sources ne sont pas retouchées.

API et modalités d’affichage des couvertures : https://openlibrary.org/dev/docs/api/covers
