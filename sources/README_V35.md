# CiviCoach — version 35

La consigne demandant de cliquer sur « Poser une autre question » a été supprimée. Les questions suivantes se saisissent directement dans le même champ.

Les réglages d’accessibilité sont regroupés dans un volet initialement replié, ouvert via « Réglages d’accessibilité ». Le message de bienvenue et la mascotte prennent ainsi la place principale à l’accueil. Les quatre profils restent dans le même encadré. Les réglages existants sont conservés et restent actifs quand le volet est replié.

Le bouton fonctionne au clavier (Entrée ou Espace), sans dépendre d’un script, grâce au composant natif details/summary.

Déployer le contenu du ZIP dans le dépôt GitHub puis recharger les onglets ouverts. Les limitations sur les adresses signalées dans README_V34.md restent identiques.
