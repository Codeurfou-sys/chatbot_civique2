# CiviCoach — version 47

Après un clic de navigation, le moteur fait défiler vers le nouveau message du chatbot, au lieu de revenir au dernier ancien message de l’apprenant. Cela évite le retour au début d’une activité lors du choix suivant ou du retour aux chapitres.

Contrôle du moteur et du DOM : la cible du défilement est le nouveau message du chatbot lors des parcours d’activité testés. Validation des écrans et liens réussie. Les fonctions des versions précédentes sont conservées.

Remplacer les fichiers et pousser sur GitHub ; attendre la réussite du workflow puis fermer les anciennes fenêtres et rouvrir CiviCoach.
