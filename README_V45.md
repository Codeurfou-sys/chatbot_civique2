# CiviCoach — version 45

Les six bases Excel sont désormais les sources de la compilation des bilans, entraînements et examens blancs. Le workflow GitHub Actions fourni relit les bases à chaque push sur main, contrôle le contenu généré et publie le site.

Contrôle des bases livrées : CSP 189 questions et 185 situations ; carte de résident 204 et 204 ; naturalisation 257 et 247. Les 650 questions et les 636 situations sont accessibles dans les parcours après correction de la couverture de douze situations auparavant absentes des séries.

Les interfaces de la version 44 sont conservées. Le chargement du script de reprise du précédent bilan, absent de la page, est corrigé et testé depuis la liste réelle de scripts de la page.

Lire ACTUALISER_BANQUES.md pour l’installation unique dans GitHub Pages et les fichiers à modifier par la suite. Le workflow n’a pas été exécuté sur le dépôt distant dans cette conversation.
