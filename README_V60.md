# CiviCoach v60

Le design manuscrit validé est conservé. Les illustrations suivent le sujet visé : personne, œuvre, résidence, institution, action ou territoire. Les œuvres et les courts repères vérifiés sont détaillés dans SOURCES_FICHES_V60.md.

Le même moteur produit les fiches des bilans initiaux et de progression, des examens blancs, des entraînements, des mises en situation, du parcours personnalisé et des enregistrements. Les profils de daltonisme, le contraste et la taille du texte sont pris en compte. Pas de fiche sans erreur ; pagination automatique et regroupement des notions par thématique.

Les erreurs identifiées ont été corrigées dans les bases Excel. Les identifiants sont conservés. La reconstruction GitHub lit les bases modifiées et conserve les PNG transparents du modèle validé.

## Installation

Décompresser puis remplacer tous les fichiers du site, y compris sources, scripts et .github, par le contenu de ce ZIP. Pousser sur GitHub et attendre la fin de l’action. Actualiser le navigateur avec Ctrl+F5. Télécharger de nouveau les fiches depuis les enregistrements : un PDF déjà téléchargé ne se met pas à jour.

Pour une notion entièrement nouvelle ajoutée ensuite dans Excel, vérifier l’association à son dessin avant publication.
