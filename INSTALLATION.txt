CHATBOT CIVIQUE V3 — INSTALLATION DES CORRECTIFS

1. Fermez les fichiers du projet éventuellement ouverts.
2. Copiez tout le contenu de ce dossier à la racine de votre dépôt Chatbot_civique2.
3. Acceptez le remplacement des fichiers existants.
4. Dans GitHub Desktop, vérifiez les changements puis créez un commit nommé :
   Correctifs pédagogiques et visuels V3
5. Cliquez sur Push origin.
6. Attendez la fin du déploiement GitHub Pages avant de tester les cartes,
   le minuteur et la recherche de proximité dans ChatMD.

FICHIERS PRINCIPAUX

- chat_bot.md : chatbot complet à charger dans ChatMD ;
- modules/02_bilan.md à modules/07_passer_examen.md : modules corrigés ;
- minuteur-examen/index.html : minuteur partagé de 45 minutes ;
- assets/cartes/ : cartes de géographie compatibles avec ChatMD ;
- recherche-centres/app.js : nouveau libellé du bouton d'inscription ;
- postprocess_module07.py : préserve la présentation du module 07 après chaque actualisation ;
- sync_module07_into_chatbot.py et le workflow : préservent le chatbot complet.
