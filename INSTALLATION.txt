INSTALLATION DU CHATBOT CIVIQUE V2

1. Décompressez ce paquet hors du dépôt GitHub.
2. Copiez tout son contenu à la racine du dossier Chatbot_civique2.
3. Acceptez le remplacement de chat_bot.md et des fichiers du dossier modules.
4. Le fichier .github/workflows/update-examens.yml remplace l'ancien workflow.
5. Dans GitHub Desktop, créez un commit : "Intégration du Chatbot Civique V2 complet".
6. Cliquez sur Push origin.
7. Testez le fichier complet dans ChatMD avec son URL raw GitHub.

IMPORTANT
Le workflow a été sécurisé : l'actualisation quotidienne des sessions ne
remplace plus l'ensemble du chatbot. Elle actualise uniquement le module 07.
