CHATBOT CIVIQUE — VERSION FINALE

1. Copiez tout le contenu de ce dossier à la racine du dépôt Chatbot_civique2.
2. Acceptez le remplacement des fichiers existants.
3. Dans GitHub Desktop, créez un commit puis cliquez sur Push origin.
4. Attendez la fin du déploiement GitHub Pages.
5. Testez le fichier chat_bot.md avec son adresse raw.githubusercontent.com dans ChatMD.

Cette version contient les dix rubriques : accueil/aide, bilan, révisions, glossaire,
préparation, entraînement, passage de l'examen, conseils, FAQ et questions libres.

Le bouton « Poser une question » est présent dans tous les écrans des modules.
Les réponses restent déterministes et proviennent des contenus validés du chatbot.
L'automatisation quotidienne continue de ne remplacer que le module 07.
