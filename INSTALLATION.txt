VERSION PROPRE ET OPÉRATIONNELLE DU CHATBOT CIVIQUE

1. Décompressez l'archive hors du dépôt GitHub.
2. Copiez tout son contenu à la racine de votre dépôt Chatbot_civique2.
3. Acceptez le remplacement des fichiers existants.
4. Double-cliquez sur NETTOYER_ANCIENS_FICHIERS.bat depuis la racine du dépôt.
   Le script supprime uniquement les doublons et anciennes versions recensés.
   Il ne touche pas au dossier caché .git.
5. Dans GitHub Desktop, vérifiez les suppressions et modifications affichées.
6. Faites un commit, puis Push origin.
7. Relancez l'action Actualiser les sessions d'examen.
8. Attendez le redéploiement GitHub Pages.
