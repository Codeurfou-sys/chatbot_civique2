# CiviCoach v58

Cette version applique la nouvelle mise en page des fiches de révision aux bilans, examens, entraînements et activités. Elle utilise une police manuscrite, des annotations, des repères visuels et des blocs regroupés par sujet. Sept illustrations ont été retravaillées : président, Élysée, Bastille, école, carte Vitale, entretien et Albert Camus.

Les réglages de daltonisme et de taille du texte sont repris dans les téléchargements. Les scores et les bases de questions restent conservés. Trois exemples PDF sont fournis dans exemples.

Installation : extraire le ZIP, remplacer les fichiers du projet, y compris chatbot/vendor et chatbot/assets, puis effectuer le commit et le push sur GitHub. Après le déploiement, actualiser la page avec Ctrl+F5 et télécharger de nouveau les fiches depuis les enregistrements. Un ancien PDF déjà téléchargé reste inchangé.

Vérification : node scripts/validate_fiches_v58.cjs.
