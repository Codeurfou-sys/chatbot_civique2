# Version 36 — PDF et plans d’action

Le PDF conserve uniquement le résultat le plus récent par catégorie : bilan, entraînement, examen blanc. La sélection repose sur la date de la tentative, et non sur la dernière tentative consultée.

Chaque thématique évaluée est accompagnée de quatre étapes issues du parcours personnalisé et adaptées au score (<40 %, 40–79 %, 80–99 %, 100 %). Les thématiques apparaissent du score relatif le plus faible au plus élevé. Le plan de l’examen blanc applique cette même progression pédagogique à ses propres résultats par thématique. Les thématiques non évaluées dans un entraînement ne reçoivent pas de conseil artificiel.

Les vingt dernières tentatives restent conservées dans le chatbot. L’export ne modifie ni la progression ni l’historique. Le bandeau rouge et le logo FRATE sont conservés. Des liens permettent de rouvrir les révisions de chaque thématique.

Les anciennes tentatives dépourvues de détail thématique sont indiquées comme telles. Les révisions enregistrées restent présentes dans l’export.

Déployer les fichiers du ZIP dans le dépôt puis recharger les onglets déjà ouverts.
