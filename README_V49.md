# CiviCoach — version 49

Relecture des textes du chatbot : coquilles, accents, accords et formulations. Les références officielles et les corrections détaillées sont dans `RELECTURE_V49.md`.

Les bases Excel sont conservées. Les corrections connues sont appliquées à l’import des textes affichés pour ne pas être perdues lors des prochaines compilations. Les nouvelles phrases ajoutées dans un Excel doivent toujours être relues.

Les libellés des feedbacks emploient désormais le singulier ou le pluriel correspondant, dont « Revoir l’erreur » / « Revoir les erreurs ».

## Installation

1. Décompressez le ZIP.
2. Copiez son contenu à la racine de votre dépôt GitHub, en conservant le dossier `.github` et ses workflows.
3. Faites le commit et le push avec GitHub Desktop.
4. Attendez que le déploiement GitHub Actions soit terminé avec succès.
5. Fermez puis rouvrez le chatbot et actualisez la page si nécessaire.

Les améliorations des versions précédentes sont incluses : reprise du bilan précédent, parcours personnalisé, questions en cours d’activité, défilement, réglages d’accessibilité, lecture et ouverture en grand dans un nouvel onglet.
